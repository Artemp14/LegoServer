Custom Web Client Template

This is a custom landing page configured for GitHub Pages deployment. Full-scale Eaglercraft builds require large pre-compiled engine files (like classes.js and assets) that exceed standard single-file scripts.

To run your multiplayer environment, ensure your workspace references your WebSocket server arrays in your configuration block below.

// Configuration Arrays Template
const eaglercraftOpts = {
  container: "game_canvas",
  assetsURI: "assets.epk",
  servers: [
    { addr: "wss://archmc.net", name: "ArchMC" }
  ]
};
