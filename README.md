# Lego Simulator

A 3D-styled interactive virtual Lego building interface.

## Features
- **Interactive Countertop:** Drag-and-drop brick stacking grid interface.
- **Beach Backdrop:** Scenic coastal window view from your kitchen counter.
- **Dynamic Snapping:** Automatically aligns lego studs together smoothly.

## How to Deploy
1. Upload these files to a public GitHub Repository.
2. Turn on GitHub Pages via settings to play it directly from your web link!
